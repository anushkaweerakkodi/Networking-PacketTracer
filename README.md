# Cisco Packet Tracer - Networking Projects

This repository contains key networking projects completed. These projects demonstrate my skills in basic router configuration, switching, and inter-VLAN routing using Cisco Packet Tracer.

## Projects Overview

### 1. Basic Router & Switch Configuration
* **Goal:** Setting up a functional local area network (LAN) with basic security.
* **Key Tasks:** * Assigning IPv4 addresses to PCs and Routers.
    * Securing the Router using Console and Enable Secret passwords.
    * Connectivity testing using the `ping` command.

### 2. VLAN Configuration & Management
* **Goal:** Segmenting a network for better security and efficiency.
* **Key Tasks:** * Creating VLAN 10 (HR) and VLAN 20 (IT) on a Cisco 2960 Switch.
    * Assigning specific switch ports to their respective VLANs.
    * Demonstrating network isolation between different departments.

### 3. Inter-VLAN Routing (Router-on-a-Stick)
* **Goal:** Enabling communication between different VLANs.
* **Key Tasks:** * Configuring a Router with sub-interfaces for each VLAN.
    * Setting up **802.1Q (Dot1Q)** encapsulation.
    * Configuring Trunk ports on the Switch to allow multi-VLAN traffic.
    * Successful cross-VLAN communication testing.
 
### 4. DHCP Server Configuration
* **Goal:** Automating IP address assignment for network devices.
* **Key Tasks:**
    * Configuring the Router as a DHCP Server.
    * Defining IP pools (`network`, `default-router`, `dns-server`).
    * Excluding specific IP addresses for gateway and static use.
    * Verifying dynamic IP assignment on end-user PCs.

### 5: Secure Wireless LAN (WLAN)
*  - Configuring a Wireless Router with WPA2-PSK security and managing SSID broadcasting to secure endpoint connections (Laptops/Smartphones).

## Technical Skills Demonstrated
* **Cisco IOS CLI:** Proficient in command-line interface configurations.
* **Switching:** VLANs, Trunking, and Access port configuration.
* **Routing:** Inter-VLAN routing (Router-on-a-stick) and Basic Gateway configuration.
* **Network Services:** Configuring DHCP Server pools and IP exclusions.
* **Network Security:** Basic device hardening, passwords, and access security.
